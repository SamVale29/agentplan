# Release notes

## 0.1.0 — 2026-08-05

AgentPlan's initial public release establishes a local-first planning, authorization and audit boundary for AI agent actions.

### Included

- Canonical action and plan schemas with runtime validation.
- Deterministic risk scoring and explainable deny-by-default policy evaluation.
- Hash-bound approvals, local audit events, redaction and drift detection.
- Filesystem, shell, HTTP, MCP and provider-normalization adapter boundaries.
- TypeScript SDK, CLI, local dashboard and executable examples.
- English canonical documentation with a complete Brazilian Portuguese README.
- GitHub Actions CI, issue templates, pull request template and Dependabot configuration.

### Early-release boundaries

This is a pre-1.0 release. It does not provide universal operating-system sandboxing, perfect prediction of future agent actions, guaranteed rollback for arbitrary side effects, complete provider API clients, distributed execution, enterprise identity or remote telemetry.
