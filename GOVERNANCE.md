# Governance

AgentPlan is maintained as an open-source project by its maintainers and contributors.

## Maintainer

The initial project maintainer is [Sam Vale](https://github.com/SamVale29). The maintainer is responsible for repository administration, release decisions, security coordination and final decisions when consensus cannot be reached.

## Decision making

Day-to-day changes are proposed through pull requests and should include tests, documentation and a clear explanation of security impact. Maintainers seek consensus in review. Changes that affect policy semantics, approval boundaries, plan integrity or public APIs require explicit maintainer review.

## Contributions

Contributors should read [CONTRIBUTING.md](CONTRIBUTING.md), use the pull request template and keep technical discussion in English. Community issues and discussions may be written in English or Brazilian Portuguese.

## Security decisions

Do not disclose security vulnerabilities in a public issue. Follow the process in [SECURITY.md](SECURITY.md). Maintainers may delay a release or revert a change when it could weaken the authorization boundary or expose sensitive data.

## Changes to governance

Governance changes are ordinary pull requests, but they require maintainer approval and must explain the effect on contributors, releases or decision rights.
